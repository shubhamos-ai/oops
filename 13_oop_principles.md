# OOP Principles and Concepts

## What is Object Oriented Programming (OOP)?
OOP is a programming paradigm that organizes code into **objects** — instances of classes that bundle data and behavior together.

## OOP vs POP (Procedure Oriented Programming)

| Feature              | OOP                              | POP                              |
|----------------------|----------------------------------|----------------------------------|
| Approach             | Object-based                    | Function-based                  |
| Data                 | Encapsulated in objects          | Global/local variables          |
| Reusability          | Inheritance                      | Copy-paste                      |
| Data Hiding          | Yes (encapsulation)              | No                              |
| Polymorphism         | Supported                       | Not supported                   |
| Modularity           | High                            | Low                             |
| Examples             | C++, Java, Python               | C, Fortran, Pascal              |

## Four Pillars of OOP

### 1. Encapsulation
- Bundling data and methods into a single unit (class)
- Data hiding through access specifiers
- Controlled access via public methods

### 2. Abstraction
- Hiding implementation details
- Showing only essential features
- Achieved through abstract classes and interfaces

### 3. Inheritance
- Mechanism to acquire properties from parent class
- Code reusability
- Types: Single, Multiple, Multilevel, Hierarchical, Hybrid

### 4. Polymorphism
- "Many forms" — same function, different behaviors
- Compile-time: Function/Operator overloading
- Run-time: Virtual functions

## Benefits of OOP
1. **Modularity** — independent class definitions
2. **Reusability** — inheritance and composition
3. **Data Hiding** — encapsulation protects data
4. **Easy Maintenance** — changes in one class don't affect others
5. **Real-world Modeling** — natural way to represent entities
6. **Polymorphism** — flexible and extensible code
